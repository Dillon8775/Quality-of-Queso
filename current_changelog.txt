- You can now quickly equip an item in your inventory by hovering and right-clicking the item (you can also still use the "B" key if you'd like).

- If the user is holding down the CTRL button in an inventory menu (chest, inventory, creative, etc.), the game will no longer automatically begin typing in its respective menu search bar.
This means holding down control in your survival inventory will no longer automatically begin typing in the recipe book. Same thing with chest search bars, and any other search bar.

- You can now search items which have a custom name via the item frame searching feature.
- You can now match item name case with the item frame searching feature. Hold CTRL over the "Search" button in the item frame GUI to match item name case.

- Added the option "Prevent E from typing", which prevents the E key from automatically typing in inventory screens (instead, it closes the inventory screen). This only applies to the survival and creative inventory menus.
- Added a "Helpful Tooltips" option, which displays all helpful quality of queso tooltips.

- Added indications when using inventory sorting features.
Arrows now appear blue when filtering by tag.
Arrows now appear red when excluding items.
Arrows now appear green when filtering by the cursor stack.

- The option "Require ALT to move" is now OFF by default.
- Removed the capitalization of "QUESO" in the mod name (now "Quality of Queso").
- Tweaks and optimizations.
