# Version 1.7.19

## Changes
- Now requires [DillonLib](https://modrinth.com/mod/dillon-lib) version 1.2.4 or greater.
- Removed and discontinued the Quality of Queso Fandom Wiki. It has been replaced with Dillon's informative YouTube videos, which are much easier to maintain and upkeep, and are also more engaging and easier to understand.
  - Watch those videos [here](https://www.youtube.com/playlist?list=PLwrfa61ofGnU2iEYEUsipCO5QNJYpr3UV) if you'd like.
- You must be in a world to change the visual time.
- Pressing space no longer auto focuses search bars.
- Removed all "Feature not available in MC *version* or below" tooltips from options.
- Replaced the "Resources..." button with *just* the Resource Pack Template button.
- Removed all socials.

## Bugs Fixed
- [#40:](https://github.com/Dillon8775/Quality-of-Queso/issues/40) Shulker boxes do not correctly remember their filter state, filter items or locked slots when remained placed on the ground.
  - This bug fix comes with other small bug fixes to filtering, possibly related to chests and other containers. *Please* report any bugs you may find to the [GitHub Issue Tracker](https://github.com/Dillon8775/Quality-of-Queso/issues).
- [#41:](https://github.com/Dillon8775/Quality-of-Queso/issues/41) Minecart containers display the "Shift+left-click this container to filter it" tooltip, when it is not possible to do so.
- [#42:](https://github.com/Dillon8775/Quality-of-Queso/issues/42) Disabling Enhanced Durability Tooltips does not display the default durability tooltip.
- Disabling a fog option completely blocks out modifying fog intensity, even if it's re-enabled.
