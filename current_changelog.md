# Quality of Queso Version 1.7.4 (MC 26.1.2 and 1.21.11 *only*)

## Quality of Queso now requires [YetAnotherConfigLib](https://modrinth.com/mod/yacl). This is the configuration system that I have decided to be use from this point forward.
- It's `simple`, `effective`, and `easy to understand`.
- It also allows for `more in-depth explanation with certain options`, which is why `I like it` and `chose it`.
---
- Revamped the `configuration screen`.
  - The `Quality of Queso main menu still exists`, but now, instead of having `each category of options within the main menu`, there is `simply one "Configure..." button`, which takes you to the **[YetAnotherConfigLib](https://modrinth.com/mod/yacl)** config screen.
    - Some options have `also` been moved to `different categories`, to keep it `simplified and organized`.
  - The `resources`, `screenshots`, `open world directory`, `keybinds` and `debug huds buttons all still exist` in the `Quality of Queso main menu`.
  - The `"visual time"` also remain in the `Quality of Queso main menu`, because it's `easier to configurate there`.

---

## Visual Time Change
- The `visual time options screen` has been completely revamped to appear `more user-friendly`, unlike an `options screen` and more of a `user-accessible interface`.
- There is now a `keybind` to open the `visual time GUI`: `CTRL + V`.
- Renamed `"Match w/ IRL Time"` to `"Sync Local Time"`.

## Use Legacy Textures Option
- A new `accessiblity` option to use `Quality of Queso's original (or legacy) button textures`.

## Button Order Option
- A new `management` option, located at the bottom of the new `YALC "management" category`, where you can `configure what order management buttons display in`.

## Other Changes
- The `visual time` and `item frame searching` screens no longer `pause the game`.
- Setting the `Quick Search` option to `"Recipe Book"` no longer auto-focuses into the `creative menu search bar`.
- Using the `Save Search Text` option now restores the `creative menu's last search text`.
- Right-clicking on the `creative menu search bar` now clears it, just like `Quality of Queso's container search bar`.
- Renamed `"Shift Recipe Book"` option to `"No Recipe Book Shift"`.
- Removed the `blacklisted servers` option. `Blacklisted servers are now handled directly via the pause screen`.
- You can no longer `shift the "Done" button` in the Quality of Queso main menu to open the `config directory`.
- `Searching Inside Transportables` and `Saving Excluded Slots` are now stored `in-memory` instead of local config file.
- `Button textures` are now rendered as `sprites`.
