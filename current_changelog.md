# Quality of Queso Version 1.6.4 (MC Fabric 26.1, NeoForge 26.1):

# Armor Ding
- Plays a ding sound whenever a player's armor piece reaches 10% durability.
- Enabled by default, togglable via config.

## Management Changes
- The transfer container button now appears in brewing stands, hoppers, furnaces, and droppers/dispeners.
- The transfer inventory button now appears in hoppers and droppers/dispeners.
  - These buttons on these screens will always display *vertically*, regardless of the option you have set.
- "Button Layout" is now set to horizontal by default (based on fans opinions!).

## NeoForge BugFix
- Fixed bug where joining a NeoForge server that doesn't have the Quality of Queso mod installed will not allow connection.
- Small NeoForge bugfix with blacklist server button.

## Fabric Changes
- (Fabric only) The mod now requires Fabric Loader version **0.18.5.**

## Screenshots Folder Button
- Added a "open screenshots button" to the Quality of Queso main menu.

## Option Changes
- "Prevent E from typing" is now on by default (it should have been before, but it wasn't lol).
- "Item Count" is now set to "Stacks" by default.
- Renamed "Item Count" to "Item Counter".
- Renamed "Show Arrow Count" to "Show Arrow Counter".
- Renamed "Enchanting Helper" to "Enchantment Helper".
- Renamed "QoQ Buttons" option to "Menu Button".

# Other Changes
- Enchantment Helper tweaks.
  - Enchantments for item types are now translatable.
- Moved some options around for easier access and readability.
- Moved a couple of textures around.
- Another small bug fix.
- Small tweaks and optimizations.
- Fortnite battle pass.
