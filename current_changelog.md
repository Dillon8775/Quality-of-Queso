# Quality of Queso Version 1.7.2 *(1.20.1, 1.21.1, 1.21.11 & 26.1.2)*

---

# Changes
- You can now hold `CTRL + SHIFT` in your inventory to `drop a full stack of the hovered locked slot.`
- The `search transportables button` now only displays if the `search bar` has a query.

## Bugs Fixed
- Fixed bug where the armor status can use the "locked" outline if the selected hotbar slot is locked.
- Fixed bug where the move single count can be modified if using the new singular moving mechanic.
- Fixed `1.20.1 bug` where the arrow counter defaults to a normal arrow after unholding a bow.
- Fixed `1.20.1` tooltip inconsistency bug.
