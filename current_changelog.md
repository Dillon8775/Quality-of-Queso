# Quality of Queso Version 1.6.4 (MC Fabric 26.1, NeoForge 26.1):

# Armor Ding
- Plays a ding sound whenever a player's armor piece reaches 10% durability.
- Enabled by default, togglable via config.

## Button Changes
- The transfer container button now appears in brewing stands, hoppers, furnaces, and droppers/dispeners.
- The transfer inventory button now appears in hoppers and droppers/dispeners.
  - These buttons on these screens will always display *vertically*, regardless of the option you have set.

## Compatibility Changes
- (Fabric only) - The mod now requires Fabric Loader version **0.18.5.**

# Other Changes
- "Prevent E from typing" is now on by default (it should have been before, but it wasn't lol).
- Enchantment Helper tweaks.
  - Enchantments for item types are now translatable.
- Small bug fix.
