# Version 1.7.12

## Now requires [DillonLib](https://modrinth.com/mod/dillon-lib) in order to run (26.2 and above only).

## Bugs Fixed
- "Optimize Item Argument" is now off by default. This fixes a bug where you can't give yourself special items with components or custom data.
- (Fabric 26.2 and above only) Fixed bug where Quality of Queso menu button on title screen overlaps with Minecraft's "Accessibility..." options button if [Mod Menu](https://modrinth.com/mod/modmenu) is not installed.
