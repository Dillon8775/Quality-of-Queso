# Quality of Queso Version 1.7.5

## Beta Warning
- Quality of Queso for Minecraft versions `1.21.1` and `1.20.1` are `officially marked as "beta"`, due to the amount of `incompatibility issues` and `bugs` found in these versions.
    - Versions for `1.21.11` and `the latest MC version (26.x)` are marked as `official/stable releases`.
- Additionally, the user `will be warned upon game startup if their version is a beta version`.

## Changes
- `Management sounds` are now `bounded to Minecraft's default sound files`, but still provide `their own subtitles`.
- Slightly `tweaked options screen`.
- Reverted back to `original button rendering`.

## Bugs Fixed
- `Quick Searching` does not work with the `recipe book`.
- `Drag Sorting` does not work properly.
- `Transfer button` does not move w/ the `recipe book` in `furnace screens`.
- `Other buttons` do not move properly w/ the `recipe book` on `1.21.1 and below`.
- `Inconsistent mod description` on `different Minecraft versions`.
- `"Dark Disc"`'s `"default"` value is `false`.
- `View Last Known Ender Chest keybind` does not work if `item frame searching` is disabled.
